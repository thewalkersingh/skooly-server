Test Flow in Postman
Step 1 — Login as ADMIN:
POST /auth/login
{
    "identifier": "admin@skooly.com",
    "password": "Admin@1234"
}
Expected: accessToken + refreshToken in response.

Step 2 — Test protected endpoint:
GET /schools
Authorization: Bearer {accessToken}
Expected: list of schools.

Step 3 — Register a new Teacher:
POST /auth/register
{
    "firstName": "Ravi",
    "lastName": "Kumar",
    "phone": "9876543210",
    "email": "ravi@test.com",
    "gender": "MALE",
    "role": "TEACHER",
    "schoolId": 1
}
Expected: "Account pending admin approval"

Step 4 — Check pending approvals (as ADMIN):
GET /users/pending
Authorization: Bearer {adminToken}
Expected: Ravi Kumar in the list with status: PENDING

Step 5 — Approve the account:
POST /auth/approve/{userId}
Authorization: Bearer {adminToken}
Expected: "Account approved successfully" + OTP sent to email/phone (check logs since email is dummy)

Step 6 — Check OTP in logs:
Since mail is dummy, check your Spring Boot console for:
[SMS STUB] To: 9876543210 | Message: Your Skooly OTP is: 482910

Step 7 — Set password (first login):
POST /auth/set-password
{
    "identifier": "9876543210",
    "otp": "482910",
    "newPassword": "Teacher@1234",
    "confirmPassword": "Teacher@1234"
}
Expected: accessToken + refreshToken — fully logged in.

Step 8 — Test RBAC:
# Should work — TEACHER can read schools
GET /schools
Authorization: Bearer {teacherToken}

# Should fail 403 — TEACHER cannot create schools
POST /schools
Authorization: Bearer {teacherToken}

Step 9 — Refresh token:
POST /auth/refresh?refreshToken={refreshToken}
Expected: new accessToken + new refreshToken

Step 10 — Logout:
POST /auth/logout?refreshToken={refreshToken}
Expected: "Logged out successfully" — old refresh token revoked.
